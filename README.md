## 🚀 Featured Projects

### 🔗 Peer Link — Anonymous P2P Chat & File Sharing
A peer-to-peer chat and file-sharing application built with WebRTC. A Socket.IO signalling server coordinates connections, while messages and files are not stored on the server. Includes SHA-256 file verification and containerised deployment.

**Stack:** React · WebRTC · Node.js · Express · Socket.IO · Docker · CI/CD

### 🧑‍💻 DevDeck Studio — In-Browser Code Workbench
A browser-based code workbench and snippet manager with a Monaco editor. Runs Python through Pyodide and JavaScript in Web Workers without server-side code execution. Includes snippet organisation and sharing roles such as read-only and can-edit.

**Stack:** React · TypeScript · Node.js · Express · MongoDB · Monaco Editor · Pyodide · Web Workers · JWT · RBAC

### ⚡ ProxyFlow — Multi-Tenant API Gateway
A reverse proxy that routes requests by path prefix, isolates tenant traffic, and stores API keys as SHA-256 hashes. Separates configuration storage in PostgreSQL from request logs in MongoDB, with a live dashboard.

**Stack:** React · TypeScript · Node.js · Express · PostgreSQL · MongoDB · Docker · Tailwind CSS
